JUAN'S TRAINING — iPhone PWA

This is the first installable version of the workout app.

Files:
- index.html — app
- manifest.json — iPhone Home Screen metadata
- sw.js — offline cache

To install on iPhone:
1. Host these files on an HTTPS website (GitHub Pages is a simple option).
2. Open the site in Safari on your iPhone.
3. Tap Share.
4. Tap "Add to Home Screen".
5. Tap Add.

This version includes:
- One-month-at-a-time calendar
- Tap dates to see workouts
- Tap workouts for details
- Calendar / Workouts / Progress tabs
- Local, offline-capable shell

Next iterations can add the complete plan, workout editing, check-offs, notes, progress tracking, Garmin integration, and data persistence.
